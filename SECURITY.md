# Security policy

Please report a vulnerability privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue.

Include the connector version, your platform, and the steps that show the problem. We acknowledge a report within three working days and keep you informed until it is resolved.

Only the latest release receives fixes. Verify every download as described in the [README](README.md#verify-the-download).
